# Neptune

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Status](https://img.shields.io/badge/status-stable-green)
![Audio](https://img.shields.io/badge/audio-Lossless-orange)

Neptune is a dedicated music extension for Echo Player, exclusively designed to stream music by **TheNewGessiko** and **Nayelina** in high-quality audio.

## Supported Artists

- TheNewGessiko
- Nayelina

## Audio Quality

| Format | Quality |
|--------|---------|
| FLAC | Lossless |
| MPEG (MP3) | 320 kbps |
| MPEG (MP3) | 128 kbps |

## Features

- Exclusive access to both artists' music catalogs.
- High-quality lossless audio streaming.
- Multiple audio quality options.
- Upcoming releases and spoilers support.
- Optional upcoming releases and spoilers toggle.
- English extension settings.

## Installation

1. Visit the [GitHub Releases](https://github.com/thenewgessiko/neptune-echo-extension/releases) page.
2. Download the latest stable version.
3. Import the extension into Echo Player.
4. Enjoy the music.

## Important

Neptune is not a general-purpose music provider.
It exclusively supports music by TheNewGessiko and Nayelina.
